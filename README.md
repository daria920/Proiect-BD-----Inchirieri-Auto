# Aplicație de monitorizare a închirierilor de mașini

Proiect individual pentru disciplina **Proiectarea Bazelor de Date**.

## Autor
- Student: [Petruska Daria]
- Grupa: [2]
- Cadru didactic: [Vaduva Bogdan]

## Scop
Proiectarea unei baze de date relaționale pentru o firmă de închirieri de mașini și realizarea unei aplicații Java conectate la aceasta. Soluția va organiza datele despre clienți, mașini, rezervări, contracte și plăți.

## Tehnologii
- Aplicație: Java.
- SGBD: de stabilit în funcție de cerințele laboratorului.
- Interfață: de stabilit.
- Componentă IA: tehnologia va fi aleasă ulterior; aplicația principală rămâne în Java.

## Funcționalități propuse
- Gestionarea clienților și mașinilor.
- Verificarea disponibilității și gestionarea rezervărilor.
- Înregistrarea contractelor, returnărilor și plăților.
- Rapoarte SQL și operații CRUD.
- Flux BD–IA, cu salvarea rezultatelor în baza de date.

## Structură de lucru propusă
- `docs/`: documentația Word.
- `diagrams/`: diagrame și sursele lor.
- `sql/`: scripturi DDL, date fictive, interogări și teste de constrângeri.
- `app/`: aplicația Java.
- `ml/`: componenta IA, realizată în etapa dedicată.
- `presentation/`: prezentarea finală.

## Urmărirea progresului
Commit-uri mici și săptămânale. Tag-uri la finalul etapelor: `v0.1-analiza`, `v0.2-proiectare`, `v1.0-final`. Nu se publică parole sau date personale reale ale clienților.
